Présentation

TurboInt Studio Launcher installe et met à jour tout ce qu'il faut pour jouer sur le serveur TurboInt Studio, puis lance le jeu et vous connecte au serveur. Un seul programme : rien d'autre à installer.

Ce qu'il fait

  • Connexion avec votre compte Microsoft (le compte qui possède Minecraft : Java Edition).
  • Téléchargement de Minecraft, de Java et de Fabric depuis les serveurs officiels.
  • Installation et mise à jour des mods du serveur, avec vérification de leur intégrité.
  • Lancement du jeu et connexion directe au serveur.
  • Affichage de l'état du serveur et des actualités.

Prérequis

  • Un compte Microsoft possédant Minecraft : Java Edition.
  • Windows 10 ou 11 (autres systèmes ultérieurement).
  • Une connexion Internet.

Overview

TurboInt Studio Launcher installs and updates everything you need to play on the TurboInt Studio server, then starts the game and connects you to the server. One program: nothing else to install.

What it does

  • Signs you in with your Microsoft account (the account that owns Minecraft: Java Edition).
  • Downloads Minecraft, Java and Fabric from the official servers.
  • Installs and updates the server's mods, checking their integrity.
  • Starts the game and connects you directly to the server.
  • Shows the server status and news.

Requirements

  • A Microsoft account that owns Minecraft: Java Edition.
  • Windows 10 or 11 (other systems later).
  • An Internet connection.
